Abstract:
The Airport Flight Scheduler is a Java-based application designed to manage and display flight information in an organized and efficient manner. The system allows users to register flights and maintain important details such as flight number, airline, origin, destination, scheduled time, gate number, and flight status. It provides features for assigning gates, delaying flights, updating flight status, displaying the departure board, searching for flights, sorting flight information, and generating reports. The system also checks for gate conflicts and validates user input to reduce errors during execution. Flight data can be saved to a text file and loaded when the program starts, allowing information to be maintained between executions. The project demonstrates Java programming concepts such as classes and objects, ArrayList, exception handling, file handling, searching, sorting, and data management. Overall, the application provides a simple command-line solution for managing airport flight schedules efficiently.
